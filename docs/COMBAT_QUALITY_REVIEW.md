# 버서커 레퍼런스 기준 전투 완성도 평가

검토일: 2026-10-31 UTC. 대상: **v0.1.7 / 6ecfb968dc659c8634ec2b37dc469304f3da5aad**. 사용자 지정 레퍼런스는 **제우스: 오만의 신의 버서커 — 대검·강한 한방**이다.

**판정: AAA 전투 연출 기준 미달. 현재 단계는 기능 프로토타입이며, 대표 강타 장면의 동작·피격·효과를 다시 저작해야 한다.** 375개 기능 회귀 검사와 배포 성공은 입력·판정·저장 계약의 근거다. 동작의 연기·실루엣·무게감·음향 믹스 승인으로 사용하지 않는다. AAA에 공인된 단일 점수표가 있는 것으로 가정하지 않고 [프로젝트 승인 기준](AAA_ART_QUALITY.md)의 구체적 항목으로 판단한다. 근거 없는 완성도 백분율은 산출하지 않았다.

## 비교 자료와 한계

- [공식 클래스 페이지](https://zeus.com2us.com/gameinfo/class)는 버서커를 대검으로 적 진형을 무너뜨리는 직업으로 설명한다. 페이지에 연결된 공식 클래스 영상은 `https://www.youtube.com/watch?v=9CmiYo06gOQ`이다.
- 같은 페이지의 공개 배경 MP4는 실제 확보해 0/3/6초 프레임을 확인했다. 2878×1280·30fps·7초·오디오 없음이며, 불꽃·불티·안면 강조·대검을 지면 가까이 둔 자세·섬광·파편을 결합한 **홍보 연출**이다. 실제 전투 입력·피격 시간·오디오·지속 성능의 기준으로 사용하지 않는다. 영상·프레임은 프로젝트 자산으로 복사하거나 배포하지 않았다.
- 원본 YouTube 전투 영상은 현재 실행 환경의 접근 제한으로 프레임 검수를 하지 못했다. 버서커의 hitstop 길이·실제 스킬 프레임·음향 품질·현재 라이브 플레이 감각을 직접 측정했다고 주장하지 않는다.
- [10월14일 공식 변경 안내](https://zeus.com2us.com/p/137fc870-5481-44dd-9ca4-205dcaab2f9e)의 HTML 본문에서 버서커 브레이브 슬래시의 발동/사용 시간 단축을 확인했다. 과거 소개 영상으로 현재 라이브의 프레임 수를 추정하지 않는다. 무거운 타격의 목표는 준비·폭발·충돌 후 관성의 대비와 반응성이며, 공격 전체를 느리게 늘이는 것을 합격 조건으로 두지 않는다.
- 현재 게임의 근거는 소스·실제 runtime GLB와 같은 커밋의 공개 웹 검사 원본이다. [차지 정지 화면](validation/combat-quality-v0.1.7/charge.png)은 실제 입력의 charge .65초 상태다. 원본 소프트웨어 WebGL은 약1fps이므로 1배속 동작 품질·목표 기기 성능 판정에 사용하지 않는다. 해당 정지 화면만으로 전체 모션을 승인하거나 기각하지 않는다.

## 이미 갖춘 부분과 혼동하면 안 되는 것

- 실제 리라 runtime은20클립·클립별159채널이다. 약공1/2는53시점, 약공3은71, heavy87, charge66의100Hz bake다. 키가2~3개라서 문제가 생긴다는 설명은 틀리다. 공식을 조밀하게 기록한 것과 개별 동작의 의미 있는 안무는 다르다.
- 현재는 최대80ms 전신 전환 보간이 실제 활성화돼 있다. 과거 보고서의 `No runtime crossfade`를 현재 결함으로 인용하지 않는다. 전환 보간의 존재와 지지발·포즈 속도·상하체 레이어 보존은 별도다.
- 실제 검 Grip/Tip의 world 이력, active 구간의 리본, 게임 공격 시간과 무기 소켓의 같은 프레임 갱신도 있다. “이펙트나 애니메이션 연동이 전혀 없다”는 판정은 틀리다.
- 일반 이동에는 stance 발 궤적 저작이 있다. 그것을 공격의 발디딤·지형 대응·전환 중 접지까지 해결한 것으로 확대하지 않는다.
- 절차 저작·수작업·모캡 중 특정 도구를 AAA의 필수 조건으로 두지 않는다. 결과의 포즈·힘 전달·접촉·타격 반응과 실제 재생 품질을 검수한다.

## 다음 제작 단위와 합격 조건

첫 단위는 **완충 강타 하나로 일반 수호병 한 명을 때리는 장면**이다. 공격·적·카메라·VFX·음향을 함께 완성한 뒤 다른 모션과 적에 확장한다.

1. **강타 동작을 독립 저작:** 지지손·지지발, 골반 선행, 검의 가속, 접촉 후 관성, 회수 자세를 설계한다. 상·하체 차지 표현과 루트 이동을 맞춘다. 무음·VFX off의 고정 카메라에서도 약공/강공/완충이 구분돼야 한다.
2. **피격자가 타격을 설명:** 전용 강피격/필요한 짧은 밀려남을 충돌과 맞춘다. 일반/방패/보스의 저항을 보존하고 명중/빗맞힘/방어/처치 결과를 구분한다.
3. **확정된 접촉 결과에서 연출:** 공격 종류·충전 강도·접촉점/법선·방향·대상 재질·방어/사망 결과를 전달해 hitpause·방향성 카메라·섬광/파편/먼지·음향층을 같은 사건에 맞춘다. 큰 ring이나 피해 숫자만으로 강도를 추측하지 않는다.
4. **실제 입력 기반1배속 AV 비교:** 같은 카메라/거리에서 약공·강공·완충의 명중/빗맞힘/방어/처치12조합을 확인한다. 발·그립·중단·복귀와 적 예고 가독성을 검수하고, 정상속도 영상·소리·목표 기기의 지속 프레임 시간을 함께 승인한다. 헤드리스/소프트웨어1fps를 정상속도·하드웨어 합격으로 사용하지 않는다.

현재 평가서는 수정 방향과 승인 조건을 기록한다. 게임 모션·전투 수치·배포 버전을 변경한 구현 완료 보고가 아니다.
