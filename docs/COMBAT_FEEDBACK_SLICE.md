# 전투 피드백·화면 연출 고도화 (v0.1.19)

제작일: 2026-11-24 UTC. 대상 버전 **0.1.19**. 사용자는 저장소를 분석해 최상급 액션 RPG로 보여 주는 데 필요한 기술을 추천안대로 적용해 달라고 요청했다. 이 문서는 추천 근거·제작 계약·검수 범위다.

## 분석: 무엇이 비어 있었나

v0.1.18까지 **공격하는 쪽**의 타격감은 촘촘하다. 확정 접촉의 양쪽 히트스톱, 칼날 잔상, 접촉 섬광·파편, 방향성 카메라 펄스, 다층 타격음, 스킬별 VFX가 있다. 반면 **맞는 쪽과 화면 전체**의 연출은 프로토타입 수준이었다.

| 영역 | v0.1.18 | 상용 액션 RPG의 일반적인 기대 |
| --- | --- | --- |
| 적 피격 | 수치·경직만 바뀌고 몸체 반응 없음 | 확정 타격 프레임에 몸체 림 섬광 |
| 적 사망 | 사망 포즈 뒤 3초에 노드가 즉시 사라짐 | 소멸 연출(불씨·디졸브)로 처치 확정감 |
| 적 체력 | 단색 사각형의 x축 스케일 | 지연 감소 잔상, 자세(poise) 게이지 |
| 공격 예고 | 머리 위 주황 사각형 | 준비 진행을 읽을 수 있는 문양과 패링 불가 구분 |
| 회피 보상 | 무적 시간만 있음 | 저스트 회피 → 슬로모·보상·잔상 |
| 화면 | 후처리 없음 | 저체력 비네트, 피격 가장자리, 강타 방사 블러, 블룸 |
| HUD | 즉시 줄어드는 바, 단색 숫자, ◇ 문자 고정 표식 | 데미지 잔상 바, 보스 자세 게이지, 강도별 숫자, 록온 레티클, 콤보 등급 |

## 적용 기술과 계약

모두 **표시 전용**이다. 피해량·자세 피해·공격 시간·판정·충돌·저장 형식·기존 애니메이션 클립과 `Engine.time_scale`을 바꾸지 않는다. 유일한 게임플레이 추가는 완벽한 회피의 Rune 보상과 적 시간 감속이다.

### 1. 적 피격 림 섬광 · `ActorFeedback`

- 확정 `receive_hit`에서만 발생한다. 강도별(약/강/차지/스킬) 길이·세기, 방패 막기는 차가운 회색, 처치 타격은 더 강하게.
- `GeometryInstance3D.material_overlay`에 가산 unshaded 프레넬 셰이더(`actor_feedback.gdshader`)를 **섬광 동안만** 붙인다. 원본 표면 재질은 교체하지 않으며 회귀 검사가 전후 재질 동일성을 확인한다.
- 리라도 피격 시 붉은 림 섬광을 같은 경로로 받는다.

### 2. 사망 불씨 디졸브

- 사망 포즈가 읽힌 뒤(1.15초) 1.45초 동안 아래에서 위로 번지는 룬 불씨 경계(모델 공간 노이즈 + 높이 바이어스)를 그리고, 경계가 실루엣 30%를 지난 뒤 몸체를 디더링으로 지운다.
- 처음 쓴 `GeometryInstance3D.transparency`는 Compatibility 렌더에서 불투명 몸체를 전혀 지우지 못했다(실제 캡처에서 3초 제거 직전까지 완전히 보임). 대신 죽는 적의 재질만 **개체별 사본**으로 바꿔 `TRANSPARENCY_ALPHA_HASH`와 albedo 알파를 낮춘다. 공유 원본 재질은 수정하지 않으며 회귀 검사가 확인한다. 끝나면 메시를 숨겨 3초 제거 전에 완전히 사라진다.
- 불씨는 파티클 노드 대신 **자체 RNG를 쓰는 MultiMesh**(균형 40, 성능 16개)와 둥근 가산 빌보드 셰이더(`ember.gdshader`)다. Godot 파티클 노드가 적 AI 쿨다운에 쓰이는 전역 RNG를 소비하지 않도록 한 프로젝트 원칙을 따른다. 회귀 검사가 전역 RNG 불변을 확인한다.
- 기존 3초 `queue_free` 수명은 그대로다.

### 3. 적 상태 판 · 공격 예고 문양

- 체력 판은 빌보드 셰이더(`enemy_status_bar.gdshader`): 기울어진 칼날형 판, 체력 색 그라데이션, 0.42초 머문 뒤 줄어드는 **데미지 잔상**, 피격 순간 밝아짐. 방패병 가드·보스처럼 누적되는 자세 수치가 있으면 아래 줄에 **자세 게이지**를 표시한다(일반 근접병은 매 타격 경직으로 자세가 초기화되므로 비어 있음).
- 공격 예고(`attack_telegraph.gdshader`)는 실제 `strike.elapsed / startup`을 읽는 마름모 룬 문양이다. 준비가 진행될수록 수축·밝아지고 마지막 15%에 흰빛 큐가 뜬다. 패링 가능한 공격은 금색, **패링 불가(보스 원형 충격파)는 적색**이다. 패링 판정 시간은 바꾸지 않는다.

### 4. 완벽한 회피 → 룬 가속(Rune Haste)

- 회피 시작 후 0.16초 안에 실제 적대 접촉(근접 스윕·투사체·보스 충격파)이 들어오면 완벽한 회피다. 회피 1회당 1번만 인정하고, 스킬·패링·부활 무적은 해당하지 않는다.
- 보상: Rune +15, 1.6초 동안 **적과 적 투사체·예고 링만 0.3배속**(마지막 0.3초에 선형 복귀). 플레이어·물리 틱·히트스톱은 실제 시간이다. `Engine.time_scale`을 바꾸면 기존 캡처 도구의 1배속 검사와 충돌하므로 의도적으로 피했다.
- 표시: 청록 잔상(균형 모드에서 현재 스켈레톤 포즈를 `bake_mesh_from_current_skeleton_pose`로 한 번 굽는 정지 메시), 화면 채도 감소·청록 그레이드·가장자리 색수차, 토스트와 패링 음의 높은 피치.

### 5. 화면 연출 `RuneScreenFX`

- 3D와 HUD 사이의 CanvasLayer. **평상시에는 아무것도 그리지 않는다.**
- 화면을 읽지 않는 비네트(저비용): 체력 35% 미만의 심장 박동 비네트(체력이 낮을수록 빨라짐), 피격 시 붉은 가장자리, 룬 가속의 청록 테두리.
- 화면을 읽는 그레이드는 룬 가속 또는 강타 순간에만 보이며 끝나면 숨긴다. 차지 강타·성역의 심판·강공 처치/자세 붕괴 접촉의 0.2초 방사 블러는 **화면 흔들림 설정을 따르고** 성능 모드에서는 생략한다.

### 6. HUD

- 플레이어 체력과 보스 체력에 지연 데미지 잔상, 보스 체력 아래 자세 게이지, 2단계 진입 시 보스 바 색 변화.
- 데미지 숫자: 외곽선, 튀어나오는 스케일, 좌우 흩어짐(HUD 전용 RNG), 강도별 크기·색(차지 금색, 스킬별 청록/보라/금), 방패 `BLOCK`, 처치 `✦`, 자세 붕괴 `BREAK`.
- 콤보: 타격마다 펀치 스케일, 5/10/20타 등급(FLOWING·RELENTLESS·RUNEBOUND), 남은 유지 시간 막대. 모바일은 상단 공간을 위해 등급 글자를 생략한다.
- 록온: 문자 대신 그려지는 레티클(안쪽을 향한 4개 갈매기표가 목표 전환 시 조여들며 천천히 회전, 보스·정예는 주황).
- 스킬 칸은 Rune이 모자라면 흐리게 표시한다.

### 7. 블룸(Glow) — 시험 후 기각

- 처음에는 균형 모드에서만 `Environment.glow`(HDR 임계 1.05)를 켜는 후보를 넣었다. Compatibility 렌더러는 [공식 비교표](research/VFX_RUNTIME_CAPABILITY_NOTES.md)상 Glow를 지원한다.
- 같은 고정 카메라 A/B에서 Glow를 켜면 블렌드 모드·강도와 무관하게, **도달할 수 없는 HDR 임계 4.0·강도 0.1에서도** 바닥 평균 RGB가 약 +3/+8/+12 오르고 표준편차가 약 22→17로 줄었다. 발광부만 번지는 것이 아니라 검증된 조명 슬라이스의 화면 전체 톤이 바뀌는 것이어서 기각했다. Glow는 끄고, 발광 VFX는 기존처럼 자체 밝기로 읽히게 한다.
- 이 관찰은 llvmpipe 소프트웨어 렌더의 결과다. 실제 GPU·브라우저에서 같은 톤 변화가 나는지와 원인(버퍼 경로 등)은 확인하지 않았다.

## 검수 범위

1. Native 회귀 `combat_feedback_regressions.gd`: 섬광 부착/해제와 재질 보존, 잔상·자세 표시, 예고 진행·위험색, 디졸브·불씨 예산, 전역 RNG 불변, 완벽한 회피의 입력·창·1회 보상·적/투사체 시간·실제 히트스톱, 리셋 정리, 화면 FX 표시 조건·쾌적성 설정, HUD 잔상·숫자 스타일, Glow가 꺼진 상태 유지.
2. 전체 native·Python 회귀와 Web/Windows 내보내기·Web 용량 예산.
3. 실제 Game 장면의 [Compatibility 렌더 정지 화면](validation/v0.1.19/README.md)(Xvfb·llvmpipe): 연출된 상태의 유한 시각 검토다. 정상 입력 플레이, 연속 시청/청취, 실기기 성능, AAA 승인이 아니다.
