# 검증 결과 · v0.1.0

검증일: 2026-10-30. Linux 클라우드 환경의 Godot **4.6.3 stable**, Blender **4.3.2**, Chromium **154**를 사용했습니다.

## 통과한 검사

- Godot 프로젝트 반입·스크립트 컴파일과 headless 전체 씬 시작. `.godot` 캐시가 없는 별도 체크아웃에서도 반입·62개 검사·웹/Windows 빌드를 통과했습니다.
- **회귀 검사 62개, 실패 0개.** 저장 버전·범위·형식 검증, 업그레이드 비용·상한, 손상된 저장의 백업 복구, 정면·후면 패링, 피격 후 무적, 스킬 자원 소모, 공격 구간 경계, 공격별 중복 피해 차단, 실제 물리 스윕, 벽 너머 피해 차단, 사망 대화·체크포인트 복귀·대상 초기화를 확인했습니다.
- 7개 전투의 적 생성, 충돌이 있는 문 잠금·해제, 완료 보상과 진행 저장, 보스 2단계 전환과 챕터 완료 저장을 통합 검사했습니다. 이 검사는 진행 상태를 직접 제어하는 자동 검사이며, 사람이 전체 챕터를 플레이한 결과가 아닙니다.
- 대화창과 HUD의 화면 내 배치, 설정 창의 제어 계층을 회귀 검사했습니다.
- 실제 Chromium에서 타이틀 → 새 게임 → 도입 대화 → 일시정지 → 복귀 → 이동 → 첫 전투 진입·공격·회피를 확인했습니다. 별도 임시 브라우저 프로필과 소프트웨어 WebGL 렌더러를 사용했습니다.
- Web release와 Windows x86_64 release 내보내기, ZIP 구성, 라이선스 포함, 웹 용량 예산과 SHA-256 매니페스트 생성.
- Python 문법, 셸 스크립트 문법과 GitHub Actions YAML 구문.

브라우저 검사는 `?qa=1`일 때만 제공하는 읽기 전용 상태를 사용합니다. 게임 상태를 변경하거나 전투를 건너뛰는 API는 제공하지 않습니다. 캡처와 오류 기록은 `build/verification/`에 생성됩니다. CI는 현재 headless 회귀 검사와 내보내기를 실행하며 Playwright 검사는 로컬 검증 도구입니다.

## 배포 확인

- 소스 저장소는 비공개로 유지합니다.
- GitHub Pages 배포 작업과 실행 아티팩트를 준비했습니다. Pages 관리 API는 연결 권한 부족으로 HTTP 403을 반환하여, 저장소 소유자의 최초 Pages 활성화가 필요합니다.
- 실제 배포 완료 여부는 Actions의 `deploy` 결과와 공개 URL의 HTTP 응답을 확인해야 합니다. 예정 주소를 배포 완료로 간주하지 않습니다.

## 미검증·후속 작업

- Windows 실기기 실행과 Forward+ 화면, Xbox 패드의 실제 입력, Edge.
- Ryzen 5 5600급·RTX 3060·RAM 16GB에서 Windows 1080p·웹 720p 60fps와 메모리 장시간 안정성.
- 신규 테스터 3명 이상의 길 찾기·난이도·30~60분 완료 시간.
- 최종 캐릭터 리그·모션·환경·음향 품질, VARCO 계정 연결과 최종 자산 제작.

현재 자산은 직접 제작한 프로토타입이며 AAA급 완성 아트나 최종 성능 검증 결과로 안내하지 않습니다.
