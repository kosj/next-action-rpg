# 실패한 최초 CI tour의 관찰

[run41161007423](https://github.com/kosj/next-action-rpg/actions/runs/41161007423)는 전투 중 품질0→1 저장검사 뒤 Escape 일시정지 대기에서 실패했습니다. 품질복원 관찰 당시 HP40·alive였고, 30초 뒤 failure-state는 HP0·dead·pausedfalse였습니다. primary의 품질0→1 커밋은 실제로 완료됐고 브라우저 오류는 없었습니다. 이 자료를 게임 저장 실패나 Escape 입력 유실의 확정 원인으로 해석하지 않습니다.

후속 tour는 실제 W입력으로 적이 없는 접근 구역(z≈−10·encounter−1)에서 두 품질/저장을 먼저 검사하고, 실제 버튼으로 재개한 뒤 기존 전투 진입·10회 공격·회피·생존 검사를 수행합니다. 게임 상태 변경·무적·검사 생략 없이 서로 다른 검사의 대기 시간을 분리합니다. 이 폴더는 과거 실패 근거이며 최신 통과 결과는 상위 폴더 및 후속 CI가 기록합니다.
