## 단계별 실패와 후속 입력

[첫 import](native-first-failure.json)는 HubNPC count 타입 추론 오류로 runner 전에 종료됐다. [001 corrected580/0](native-corrected-001-checkpoint.json)은 그 입력의 후속 성공이며 최종 geometry/압축 승인과 다르다. [Erin002](../../../art_source/production/candidates/erin-002/visual-review.json)의 부분 수선은 미채택, [Erin003](../../../art_source/production/candidates/erin-003/manifest.json)은 국소 geometry/normal/UV clone 후 actual Game에서 제한적으로 채택했다. 작은 의상 결함은 남는다.

[선택003의 첫580/export](native-selected-003-checkpoint.json), [옛149,687,995B package](local-runtime-package.json), [옛 preview](local-preview-build.json)와165.033초의 첫16장은 **NPC 접지 수정 전** 기록이다. 그 q1 boots 부유 문제를 기각한 뒤 source를 바꾸고 새601/export와99.948초 after8장을 확인했다. 이전 체크 수·용량·raster를 최종 source에 승계하지 않는다. 캡처 시간은 FPS가 아니다.

원본 GLB·raw TTF·imported fontdata 절감·CTEX 저장량·forecast·최종 PCK/raw Web/ZIP은 다른 값이다. 최종 WebZIP119,076,424B, WindowsZIP146,917,780B의 실제 bytes/SHA는 위 manifest에 고정한다. Windows export 성공은 Windows OS 실행 승인이 아니다. 선택003 embedded map→외부PNG encoded bytes와 import MD5/header는 [별도 chain](../../../art_source/production/candidates/erin-003/postimport-image-audit.json)이며, pre-paint346mip 실험을 새 pixel의 전체 decode 승인으로 옮기지 않는다.

기존 공개 묶음1.4.6은 보존한다. 다음1.4.7은 카탈로그/근거 source를 먼저 커밋한 뒤 존재하는 Git object에 고정한다. 미래 SHA·미실행 브라우저/공개 검증을 성공으로 쓰지 않는다. [v0.1.12 공개 완료](../v0.1.12/published-verification.json)는 역사적 근거다.
