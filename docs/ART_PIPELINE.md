# Blender · VARCO 제작 가이드

## 현재 자산

Blender 4.3.2의 Python API로 직접 제작한 주인공·수호병·보스·기록관의 `.blend` 원본과 `.glb`를 포함합니다. 영리 사용 조건이 불명확한 모델이나 외부 모션은 사용하지 않았습니다. 효과음과 배경 패드는 Python으로 합성한 임시 소리입니다.

```bash
blender -b --python art_source/generate_assets.py
python art_source/generate_audio.py
```

첫 명령은 4개의 Blender 원본과 GLB를 다시 생성하며 기존 파일을 덮어씁니다. 수작업으로 다듬은 원본은 별도 이름으로 보관한 뒤 실행합니다. Git LFS는 `.blend`에 적용하고, 작은 런타임 GLB는 일반 Git으로 관리합니다.

## 아트 가이드

- 리라: 성인 여성, 현실적인 인체 비례, 은회색 머리, 흑철 갑옷·청록 천·오래된 금색 장식, 청록 룬검. 얼굴과 실루엣은 독자 디자인으로 제작합니다.
- 수호병: 손상된 청동 갑옷, 잿빛 천, 주황빛 균열. 근접·방패·원거리 역할은 색 외에도 무기와 실루엣으로 구분합니다.
- 아스테르: 인간보다 큰 파수꾼, 왕관 같은 관 장식과 긴 검. 2단계에서 룬 균열이 밝아집니다.
- 환경: 순례자 구역의 밝은 돌, 회랑의 차가운 석재, 정원의 이끼, 제단의 그을음. 멀리 보이는 폐허와 발밑의 룬이 길을 안내합니다.

## VARCO에서 최종 자산으로

1. 정면·측면·후면의 비례와 재질을 먼저 합의하고 모델별 지시문을 작성합니다.
2. VARCO 3D에서 형상 초안을 생성합니다. 초기에는 기둥 장식·제단·소품·몬스터 초안을 우선합니다. 현재 저장소에는 VARCO 계정이나 API 키가 없고, 생성 서비스 API 통합은 구현하지 않았습니다.
3. GLB로 내려받아 Blender에 반입합니다. 로컬 Blender 환경이라면 [VARCO Blender Bridge](https://www.varco.ai/home/en/blog/2026-03-19-varco-3d-bridge-for-blender)를 사용할 수 있습니다. 클라우드 작업 공간과 로컬 브라우저 사이에 이 연결이 자동으로 있다고 가정하지 않습니다.
4. 비정상 면·법선·교차를 정리하고, 얼굴·손·관절의 토폴로지, UV와 재질, 리깅·웨이트를 보정합니다.
5. 공통 스켈레톤에 이동·피격·회피를 먼저 연결한 뒤, 핵심 콤보의 시작·중간·끝 자세와 발 접지를 제작합니다. 무료 모션을 사용할 때에도 출처와 재배포 조건을 기록합니다.
6. Blender에서 GLB를 명시적으로 내보내 Godot에 반입하고, 게임 씬에서 재질과 충돌·손의 무기 위치를 검수합니다. 원본 `.blend`를 런타임 프로젝트에 넣지 않습니다.

현재 `ActorVisual`은 `Torso`, `Head`, `ArmL/R`, `ElbowL/R`, `LegL/R`, `KneeL/R`, `HandL/R` 피벗을 사용합니다. 최종 리그는 이 임시 계약에 억지로 맞추기보다 ActorVisual의 표현 구현을 교체합니다.

## 반입 합격 기준

- 단위 1m, 발바닥 y=0, Godot의 -Z가 캐릭터 전방. 어깨 높이·손 위치·무기 길이를 실제 공격 판정과 비교합니다.
- 누락 텍스처와 뒤집힌 면이 없고, 걷기·회피·공격에서 관절이 꺾이거나 발이 미끄러지지 않습니다.
- 공통 PBR 재질을 기본으로 하고 Forward+ 전용 효과에는 웹용 대체 표현을 제공합니다.
- 웹 텍스처는 1~2K, 주요 Windows 자산은 2~4K를 초기 기준으로 합니다. 최종 폴리곤·드로콜 예산은 대표 전투 실측 후 확정합니다.
- 자산별 생성 도구·지시문·원본·수정 이력·사용 조건을 기록하고, 생성 크레딧이 부족하면 Blender 직접 제작으로 계속 진행합니다.
