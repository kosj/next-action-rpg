# 효과별 제작 출발점

아래는 독립 작성한 설계안이다. RedefineFX 영상 내부의 노드나 수치를 복원한 것이 아니다. 선택한 recipe의 시간·크기·색·한도는 제작 양식에 정하고 실제 장면에서 검수한다.

| 효과 | 주 형태 → 보조 레이어 | 게임 연결 / 가장 먼저 기각할 문제 |
| --- | --- | --- |
| 연기·불 | 베이크한 연기 flipbook + 얇은 불꽃 메시 → 드문 ember | 타는 대상의 소켓과 잔류 world 연기를 분리한다. 사각 경계·검은 halo·같은 프레임 반복·바닥 관통을 먼저 고친다. |
| 전기·불꽃 | 시작/끝이 명확한 분기 strip 메시 → 짧은 작은 spark | 실제 접촉점 또는 명시된 장식 anchor를 따른다. 무작위 번개가 맞지 않은 적에게 연결되거나 매 프레임 전체가 튀는 것을 피한다. |
| 링·충격파 | 지면 방향의 감쇠하는 annulus → 낮은 먼지 | 지원 바닥과 gameplay 반경을 구분한다. 시각 장식이면 피해 영역처럼 오해되지 않게 한다. 수직 벽 관통·균일한 네온 원을 검수한다. |
| 보호막 | 얇은 구면/곡면 + 국소 접촉 ripple → 가장자리 미세 입자 | 방어 성공과 소유자 좌표에 연결한다. 시야 전체를 가리는 불투명 구, 안쪽 카메라에서 사라짐, 공중의 거짓 접지 먼지를 기각한다. |
| 미사일 | 방향성 있는 작은 탄체 + 감쇠 wake → 충돌 burst | 실제 진행체 위치/차단/수명을 따른다. 지나간 이력이 발사자와 함께 회전하거나 시각만 벽 너머로 진행하지 않게 한다. |
| 포털·흡입 | 테두리 메시 + 내부 독립 셰이더 → inward 입자/제한된 파편 | 렌더 효과와 실제 이동·흡입 규칙을 구분한다. 화면 굴절이 없는 기본 경로도 구성한다. 비용 큰 파편 물리를 장식 때문에 자동 추가하지 않는다. |
| 지면 먼지·안개 | 얇은 mask/낮은 card 묶음 → 작은 drift | 실제 바닥 높이와 경사를 따른다. 이 방식은 진짜 volumetric fog가 아니며 카메라가 낮아졌을 때 card 경계를 확인한다. |

## 대검 검기: 판/흰 띠를 개선하는 순서

1. **형상만 본다.** noise·glow를 끄고 원래 진행 방향의 실루엣을 확인한다. 중앙이 두껍고 양끝이 좁아지는 곡면/얕은 쐐기, 뒤로 흐르는 꼬리를 별도 레이어로 만든다. collider가 표현하는 핵심 범위와 정면을 확인한다.
2. **공간 분포를 나눈다.** 높은 값의 작은 core, 낮은 값의 넓은 body, 빠르게 사라지는 wake를 분리한다. 전체 면을 동일한 흰색 additive로 덮지 않는다. 근거리·사선에서 두께가 보여야 한다.
3. **동작을 연결한다.** 방출 시점은 실제 베기 release와 맞추고 이동 위치는 gameplay 진행체를 따른다. 임의 shader 이동과 collider 이동을 이중 적용하지 않는다. 검의 잔상과 독립 발사체를 다른 이력으로 유지한다.
4. **경계만 흐트러뜨린다.** 끝과 꼬리의 밀도를 noise/mask로 잘게 나누되 핵심 전진 실루엣은 읽히게 남긴다. 화면 해상도가 낮아져도 noise가 점멸하거나 줄무늬가 되지 않는지 확인한다.
5. **상대에게 결과를 만든다.** 확정 접촉에서 작은 섬광·재질별 파편/먼지·피격 동작을 묶는다. 빗나감은 wave와 wake만 남아야 한다. 카메라/음향은 명중 시점과 기존 접근성 설정을 따른다.
6. **예산 안에서 비교한다.** 전후 같은 실제 gameplay 구간을 1배속으로 확인한다. 모션이 약하면 포즈·가감속·무게 전달의 별도 문제로 기록한다. VFX 크기만 키워 애니메이션 부족을 가렸다고 완료하지 않는다.

## 효과 제작 결과의 최소 구조

```text
effect/
  source/          # 원본/저작 recipe, cache 위치 및 생성 조건
  textures/        # atlas/mask와 해석 메타데이터
  meshes/          # 주 형태, pivot/단위/축
  runtime/         # 목표 엔진의 shader/material/scene 및 이벤트 연결
  review/          # 동일 조건 전후 영상, 실제 target 측정, 판정/미검증
```

디렉터리 이름은 예시다. 소스·캐시가 크면 별도 저장소/산출물에 보관하고 고정 식별자·SHA로 연결한다. atlas와 source를 런타임 패키지에 중복 포함하지 않는다.
